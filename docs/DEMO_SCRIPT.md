# OralCompass demo script (under five minutes)

The storyboard of `docs/ORALCOMPASS_DESIGN_SPEC.md` §11 with exact clicks. Every number below is generated by the engine and asserted in
tests (`engine/tests/test_fixture.py`, `engine/tests/test_real_presets.py`, `api/tests/test_records.py`) or read from the fictional
fixture records (`fixtures/users/alex.json`). Do not round, restate or add numbers that are not on screen.

## Setup (demo mode: no key, no model call)

Use a fresh data directory so the upload publishes as `UP1`, and force demo mode in the shell (shell variables override `api/.env`).

**One server (recommended for presenting):**

```bash
cd web && npm run build
cd ../api && ORALCOMPASS_DEV_AUTH=0 ORALCOMPASS_LLM_PROVIDER=none ORALCOMPASS_DATA_DIR=$(mktemp -d) \
  python3 -m uvicorn app.server:app --host 127.0.0.1 --port 8000
# open http://127.0.0.1:8000 at 1366×900
```

**Two servers (development):** API with `ORALCOMPASS_DEV_AUTH=1 ORALCOMPASS_LLM_PROVIDER=none ORALCOMPASS_DATA_DIR=$(mktemp -d)` on
`127.0.0.1:8000`, and `cd web && npm run dev` (a dev build sends the `X-Dev-User` header). A production bundle under `vite preview` needs
`VITE_DEV_AUTH=1 npm run build` to talk to a dev-auth API.

Before you start: copy the fixtures into `web/public/fixtures/` (README, step 3), keep `fixtures/documents/harborview_certificate.pdf`
in reach for the file picker, and open the app once to warm it.

## Lines to keep exact

- "Every dollar is stitched to the clause that produced it." Show it, do not just say it: press a stitch.
- "Where the document is silent, we say so." Point at an UNKNOWN badge.
- Describe each plan only by what its documents say; Compare has no ranking and no sort, by design.
- No certification or compliance claims. Personal records here are fictional; the plan rules for Alex are public.

## Fallbacks

| If | Then |
|---|---|
| The API is down or the page shows a load error | Restart the API command above (fresh `ORALCOMPASS_DATA_DIR`), reload. The web app shows an error banner, not a blank page. |
| The upload stalls or extraction says `demo_no_model` | The file is not one of the four fixture PDFs (demo mode matches by checksum). Re-pick `fixtures/documents/harborview_certificate.pdf`. |
| Publishing gives `UP2` instead of `UP1` | The data directory was reused; the numbers are the same. Restart with a fresh `ORALCOMPASS_DATA_DIR` for the next run. |
| A live-mode call is slow or refused | Say "demo mode" and continue: every AI feature has a deterministic fallback and labels it. Live extraction of the 14-page PDF takes minutes, so present in demo mode. |
| 401 errors in the browser | A production bundle is talking to a dev-auth API. Use the one-server command, or rebuild with `VITE_DEV_AUTH=1`. |
| Motion stutters on the projector | Turn on reduced motion in the OS; every end state stays intact. |
| No network at the venue | Everything above runs locally; only live mode needs the internet. |
| Anything else | Show the screenshots in `docs/screenshots/` and the tests that assert the numbers (`engine/tests/test_fixture.py`, `engine/tests/test_real_presets.py`). |
