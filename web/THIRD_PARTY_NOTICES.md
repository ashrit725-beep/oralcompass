# Third-party UI components vendored into `web/src`

Every file below was installed on **2026-10-03** by the web foundation agent following `docs/ORALCOMPASS_COMPONENT_PLAN.md` and is now
**project source**: patched, recoloured to the OralCompass tokens in `web/src/styles.css`, and committed. Re-running `shadcn add` on any
of these files is forbidden without a `--diff` review (plan §4 rule 11). Generic patches applied to every registry file: `"use client"`
stripped, `framer-motion` → `motion/react`, `dark:` classes deleted, `next/*` imports removed, `clsx(` → `cn(`, hex literals and Tailwind
gray/zinc/neutral/indigo/blue utilities replaced by token utilities (`text-ink`, `bg-paper-deep`, `stroke-sea` …) or `var(--…)`.
Licence texts for npm packages live in `node_modules/<pkg>/LICENSE`.
